# Claude Chat - Motion

A Claude-style motion chat interface with a live sky background.

## Features

- Claude-inspired chat layout with motion background
- Sky video background (single looping scene)
- Arthur Best credit badge fixed at bottom-right
- Built with Next.js, React, Tailwind CSS, and assistant-ui

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm start
```
