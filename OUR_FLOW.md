# Our Flow

## Background Change Prompt
I want to change the background. Find the best option from these sources:
- Pixabay: https://pixabay.com/videos/search/background/
- Pexels: https://www.pexels.com/search/videos/abstract/
- Mixkit: https://mixkit.co/free-stock-video/abstract/

Download the selected background and update the app.

## After Changes
After changes are made, ask:
> “Are you done with changes and ready for deployment through GitHub?”

Only prepare for GitHub deployment after I confirm.

## GitHub Deployment Rules
- Always deploy through GitHub.
- Always create a GitHub Pages website for the app.
- Always include a current app screenshot in the README so it shows on GitHub.
- Do not include resource/source links in the README; keep them for internal use only.
